# 真经 GRE 等价词闪卡（2026）

共 905 张闪卡，按 PDF 中每个词汇条目制作一张；等价词完整显示在背面。第 1–5 天分别为 180、182、181、177、185 张。

## 直接练习

用浏览器打开 `GRE等价词闪卡.html`，无需联网。选项按屏幕顺序标注 A、S、D、F、J、K、L、；，可点击或按对应键选择；不足 8 项时只使用前面的键。点击或按键选择后，该选项下方会显示原资料中的中文释义，选对、选错都会显示；刷新后已选项的释义仍会保留。正确项使用本题释义，干扰项汇集其在原资料词组中的释义。搜索框输入时不会触发答题。按空格或点击“看答案”显示全部正确选项及中文释义，同时归入“需要复习”；页面停留供阅读，再按空格进入下一题。左右方向键分别切换上一题、下一题。每题从随机选项中选出原资料本条的全部等价词，选齐后自动进入下一题。一旦选错立即归入“需要复习”，补齐正确项后仍保留复习状态；下次不出错地答对才标记为已掌握。可按天筛选、搜索、随机排序，或在“需要复习”中重练错题。学习状态沿用旧版；当前题目、筛选条件、随机顺序、已选选项和答案显示状态自动保存在当前浏览器，刷新或再次打开同一文件可继续。干扰项从词库生成，避开原资料中与当前词相连的等价词组；判题范围为本条原文，不代表词典中的所有同义关系。

## 导入 Anki

在 Anki 中选择“文件 → 导入”，选取 `Anki闪卡.tsv`。分隔符为 Tab，启用 HTML；选择只有正面和背面的基础笔记类型（Basic / 基础），第 1 列对应正面，第 2 列对应背面，第 3 列对应标签。预览确认后导入。可通过 Day1 至 Day5 标签分天学习。

## 整理范围

来源：`真经GRE等价词汇总（2026年版 ）.pdf`，PDF 第 5–29 页（原书第 1–25 页）。已去除水印和表头，合并单元格换行，统一逗号后空格，并去除末尾孤立逗号。原文词汇拼写、释义、重复等价词及语境等价关系保留，未按词典重新修订。某些等价词并非所有语境下都同义，应结合原题理解。

`词汇数据.json` 保留全部条目、任务分组和页码，供后续编辑或转换。
